# Lost Among Cards

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 게임 제목 | **Lost Among Cards** |
| 장르 | 3D Deckbuilding / Roguelike / Board Game |
| 개발 엔진 | Unreal Engine 5.4.4 |
| 플랫폼 | PC |
| 플레이 방식 | Single Player |
| 시점 | First Person |
| 예상 플레이 시간 | 20~25분 |

### 한 줄 소개

> 카드로 이루어진 테이블 위를 방황하며 선택과 판정을 반복하고, 자신만의 덱으로 최종 목표를 찾아가는 1인용 3D 덱빌딩 보드게임

---

## 2. 게임 컨셉

플레이어는 게임 시작 전 자신의 덱을 구성한다.

게임이 시작되면 플레이어 덱과 스테이지 덱의 카드가 3D 테이블 위에 배치되어 하나의 게임판을 구성한다.

플레이어는 자신의 말을 움직여 게임판을 탐색하며, 카드에 도착하면 해당 카드가 뒤집히고 카드에 적힌 상황과 선택지를 확인할 수 있다.

플레이어의 선택에 따라 이벤트나 전투가 발생하며, 상황에 맞춰 다이스, 룰렛 또는 펜듈럼 QTE를 이용하여 결과를 판정한다.

게임판에서 발생하는 상황에 따라 주변 환경과 오브젝트가 변화하여 단순한 카드 게임이 아닌 3D 보드게임을 플레이하는 듯한 몰입감을 제공한다.

### 핵심 키워드

- **Deck Build** : 플레이어가 직접 구성하는 덱
- **Explore** : 말을 움직여 게임판과 카드 탐색
- **Choice** : 카드에 제시된 상황과 선택지를 통한 의사 결정
- **Random** : 다이스와 룰렛을 이용한 결과 판정
- **QTE** : 펜듈럼을 이용한 직접 판정
- **Roguelike** : 매 플레이마다 달라지는 카드 구성과 진행

---

## 3. 게임 목표

플레이어의 최종 목표는 다음과 같다.

1. 게임 시작 전 자신의 덱을 구성한다.
2. 스테이지 덱과 플레이어 덱을 이용하여 게임판을 생성한다.
3. 말을 움직여 게임판을 탐색한다.
4. 카드를 밟아 새로운 상황과 선택지를 확인한다.
5. 선택에 따라 이벤트 및 전투를 진행한다.
6. 다이스, 룰렛 또는 펜듈럼 QTE를 통해 상황을 판정한다.
7. 보상과 새로운 카드를 획득하여 덱을 강화한다.
8. 스테이지의 최종 목표를 달성한다.
9. 최종 목표 달성 시 게임을 클리어한다.

---

## 4. Core Gameplay Loop

게임의 핵심 플레이 흐름은 다음과 같다.

```text
덱 구성
  ↓
스테이지 시작
  ↓
카드 배치
  ↓
말 이동
  ↓
카드 공개
  ↓
상황 및 선택지 확인
  ↓
선택
  ↓
다이스 / 룰렛 / 펜듈럼 QTE
  ↓
이벤트 / 전투 / 보상
  ↓
카드 및 아이템 획득
  ↓
덱 강화
  ↓
다음 카드 탐색
  ↓
최종 목표 달성
```

플레이어는 게임이 종료될 때까지 **탐색 → 선택 → 판정 → 결과 확인 → 덱 강화**의 과정을 반복한다.

## 6. 플레이어 기능

### 6.1 이동

플레이어는 3D 테이블 위에 구성된 게임판에서 자신의 말을 이동시킬 수 있다.

주요 기능:

- 앞 / 뒤 / 좌 / 우 이동
- 게임판 내 카드 탐색
- 카드와의 상호작용
- 이벤트 발생 지점 이동

### 6.2 덱 구성

게임 시작 전 플레이어가 사용할 카드를 선택하여 덱을 구성한다.

플레이어 덱은 게임 진행에 필요한 다양한 효과를 가진 카드로 구성된다.

게임 진행 중 새로운 카드를 획득하거나 기존 카드를 교체하여 자신의 플레이 방식에 맞는 덱을 구성할 수 있다.

### 6.3 카드 탐색

스테이지 덱과 플레이어 덱을 이용하여 3D 테이블 위에 게임판을 구성한다.

플레이어가 말을 이동하여 특정 카드에 도착하면 카드가 뒤집히며 해당 카드의 상황과 선택지가 표시된다.

예:

> **수상한 상자를 발견했다.**
>
> `[상자를 연다]`
>
> `[그대로 지나간다]`

선택한 행동에 따라 서로 다른 이벤트가 발생한다.

### 6.4 이벤트

게임판에서 카드를 공개하면 다양한 이벤트가 발생한다.

이벤트의 종류에 따라 주변 환경이나 오브젝트가 변화한다.

예:

- 조명이 어두워짐
- 주변 오브젝트 변화
- 새로운 카드 등장
- 특정 구역 봉쇄
- 보상 생성
- 적 등장

이를 통해 카드에 적힌 텍스트만으로 상황을 설명하면서도 3D 환경의 변화를 통해 사건이 실제로 발생하는 듯한 연출을 제공한다.

### 6.5 판정 시스템

이벤트 및 전투의 결과는 다양한 방식의 판정을 통해 결정된다.

주요 판정 방식:

- **Dice Roll** : 주사위를 굴려 결과를 결정
- **Roulette** : 룰렛을 돌려 결과를 결정
- **Pendulum QTE** : 움직이는 펜듈럼을 특정 구간에서 정지시켜 결과를 결정

플레이어의 카드 효과와 능력치에 따라 판정 결과에 보정이 적용될 수 있다.

### 6.6 전투

전투는 실시간 액션 방식이 아닌 보드게임 및 TRPG 방식으로 진행한다.

적과 조우하면 플레이어의 카드와 능력치를 기반으로 전투 상황이 결정되며, 다이스나 룰렛 등의 판정을 통해 공격과 방어의 결과를 결정한다.

전투 결과에 따라 피해, 회복, 상태이상, 아이템 획득 등의 결과가 발생한다.

### 6.7 성장

게임을 진행하면서 새로운 카드와 아이템을 획득할 수 있다.

획득한 카드를 덱에 추가하거나 기존 카드를 교체하여 이후 게임에서 사용할 덱을 변화시킬 수 있다.

### 6.8 게임판 변화

게임 중 발생하는 이벤트에 따라 3D 테이블 위의 게임판과 주변 환경이 변화한다.

카드의 결과와 연계하여 조명, 오브젝트, 이펙트 등의 변화를 발생시켜 카드의 내용을 시각적으로 표현한다.
